# 三角色前端设计示意

`index.html` 是可丢弃的独立静态设计原型，不是正式前端入口。

直接在浏览器打开即可查看，无需安装依赖。顶部切换学生、教师、管理员；学生首页点击“开始自我评价”可体验四步星级和文字表单。

所有人物、班级、数量、特长均为虚构示例，不读取或提交真实业务数据。自评内容只在当前页面内存暂存，刷新会清空；“保存”只演示交互，不能当作服务器持久化验证。部分成人业务按钮仅展示流程说明。

正式实现依据：[三角色前端与清理设计](../../superpowers/specs/2026-10-28-three-role-ux-and-cleanup-design.md)。

原型用于布局评审；最终字号、对比度、无障碍与真实接口验收以设计文档为准。
