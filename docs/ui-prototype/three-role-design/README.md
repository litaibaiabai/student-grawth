# 三角色前端设计示意

`index.html` 是可丢弃的独立静态设计原型，不是正式前端入口。

直接在浏览器打开即可查看，无需安装依赖。顶部切换学生、教师、管理员；学生首页点击“开始自我评价”可体验四步星级和文字表单。教师“＋记1分”是单页级联直评，说明选填；“卡片管理”可查看月度台账、按学生/指标过滤的流向示例，并导出示例CSV、预览打印台账。

“班级报告”展示教师负责的全部示例班级和6名虚构学生的摘要；点击学生打开独立详情，正文复用现行renderer。默认六育明细，班主任示例可切完整正反面，任课教师示例只显示明细。导出PDF通过浏览器打印面板选择“另存为PDF”，不代表服务器已提供PDF下载。详见[班级报告设计](../../superpowers/specs/2026-10-29-class-report-browser-design.md)。

所有人物、班级、数量、特长均为虚构示例，不读取或提交真实业务数据。自评内容只在当前页面内存暂存，刷新会清空；“保存”只演示交互，不能当作服务器持久化验证。部分成人业务按钮仅展示流程说明。

正式实现依据：[三角色前端与清理设计](../../superpowers/specs/2026-10-28-three-role-ux-and-cleanup-design.md)。

原型用于布局评审；最终字号、对比度、无障碍与真实接口验收以设计文档为准。
