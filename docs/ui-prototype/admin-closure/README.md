# 管理员闭环设计预览

日期：2026-11-01；性质：待确认的交互原型。

打开 `index.html` 可浏览发布中心、学籍与账号、班级管理、月度卡额度、数据统计、学期配置、操作记录七页。示例弹窗展示导入差异、班级详情、负责教师、调班影响与发布缺项；页面不请求业务接口，提交按钮只展示原型提示。

原型已按用户反馈移除管理员“体测原始值”入口，体测上传保留在教师端；报告内容审核由班主任负责，管理员核对完整性并统一发布。

修订后的班级管理：全部通过导入建立，没有手动新建；一个班级选择一位负责教师（班主任），并由管理员在“教师配置”中维护各学科教师。详情仅有“学生名单／教师配置”两个页签，不设班级状态或进度。卡片缩为原设计约四分之一面积，只显示班名、负责教师和学生人数。

月度卡额度维护统一默认数量（初始 100）及各学科覆盖值，单位为每班每月张数。未填写学科使用默认，示例语文 60、数学 70、英语 75 覆盖默认；明确填写 0 暂停该学科新卡生成。教师端按实际任课关系自动生成，没有按教师分配、下发或追加。用户已确认同师三个语文班各 60，共 180；班级负责人用于报告审核，不自动当成全部学科教师。

完整设计与迁移、测试、演示交付范围见 [管理员闭环设计](../../superpowers/specs/2026-11-01-admin-closure-design.md)。原型中的人数、进度与记录都是虚构示例，不代表真实系统状态，也不是闭环测试证据。
