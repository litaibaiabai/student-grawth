# 学期综合测评页面设计稿

> 这是前版102位置原型。用户最新PDF已有109位置，来源及流程以[学校期末报告核心工作流精简方案](../../superpowers/specs/2026-10-28-term-report-core-workflow-design.md)为准；本原型待整体设计确认后再更新，不代表最新正式页面。

根据用户提供的六板块测评明细图片制作，目标是重构系统的 `/student/evaluation` 页面。直接打开 `index.html` 即可预览，不需要启动前后端。

- 电脑：德美、智美在左；健美、艺美、劳美、故事美在右，保留表头、合并单元格和原图全部栏目。
- 手机：六板块依次纵向显示，智美按科目展开，艺美按学科展开，不省略字段。
- 星级、字母、测量值、描述独立展示；原图空白格显示待评价，不补造分数。
- 提供板块导航、待评价项标记、浏览器打印/保存 PDF。
- 所有内容均为示例，不连接真实学生数据；正式 React 页面尚未修改。

`reference.png` 为用户附件；`desktop.png`、`mobile.png` 为实际浏览器预览截图。`field-map.json` 是逐格台账，包含图片原有的 99 个位置及补充需求的 3 个故事评价位，共 102 个显示位置，含自评空格、特长名称/文字及两行可重复特长；这个数量不等于原 Word 模板的 74 个合并字段。`origin` 标记两种来源。

故事板块保留附件三项实践文字，并依据前文明确需求增加三项独立评价位；没有提供分值的格子显示待评价。字体、颜色与装饰使用学校表格风格重新整理，未复制原图卡通图标。

已使用浏览器验证 1440px 电脑宽度及 375/390/430px 手机宽度：102 个展示位置均可见，无整页横向溢出；待评价标记开关可用，无页面脚本错误。示例内容的浏览器打印校样为 A4 横向一页，并检查了实际 PDF 渲染。此结果仅验证设计稿，真实长文本的页内容量仍需在接入数据后核验。记录见 `verification.json`。

完整数据库、模块和界面修改建议见 [需求差异与修改方案](../../superpowers/specs/2026-10-28-requirements-gap-and-renovation-design.md)。
