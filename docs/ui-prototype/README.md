# 六育 · 全模块界面原型

直接用浏览器打开 `index.html`，无需安装或启动后端。页面顶栏可切换学生、教师、管理员身份，或从“模块目录”访问全部 31 个视图；“手机预览”展示窄屏效果。

这是界面设计原型，使用虚构演示数据。扫码、材料提交、人工审核、导入、规则激活、报告发布等均为本机交互演示，不执行真实业务。角色切换不代表生产权限模型。

- 学生端：8 页，含扫码、积分账本、荣誉、故事、综合评价、报告与自述。
- 教师端：9 页，含待办、审核、批量直评、班级成长、导入、期末评语与配卡统计。
- 管理端：12 页，含学期、账号、指标、配额制卡、材料、故事任务、导入、核算、发布、更正与审计。
- 通用：登录、消息中心 2 页。

完整界面说明与业务规则位于 `../superpowers/specs/2026-10-22-six-education-ui-design.md`。

源文件：`style.css` 与 `app.js`；修改后运行 `python3 build.py` 重新生成可独立打开的 `index.html`。所有资源内嵌，无网络字体、图片或 CDN 请求。草稿仅在本机浏览器保存；其他演示状态在刷新后恢复。

设计确认后，另行制定正式 React 前端实施计划并接入后端。
