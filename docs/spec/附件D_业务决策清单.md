# 附件D｜上线前需确认的15项决策

未确认条目不得被默认为校规或已经验证的外部平台能力。

## 20. 需学校/实施方最终确认的决策清单

| 编号 | 待确认问题                     | 本SPEC推荐值/处理方式                    | 谁确认        |
| ---- | ------------------------------ | ---------------------------------------- | ------------- |
| D01  | 一学年/学期命名与school_id维度 | `academic_year`保留，业务表另存school_id | 管理员/技术   |
| D02  | 教师`classes` JSON实际数据格式 | 后端统一解析；格式不合规则拒绝           | 技术/教务     |
| D03  | 每名教师每月N张卡及分配类目    | 管理员配置总数与分类分布，按月固化       | 校领导/管理员 |
| D04  | 月末待审宽限期                 | 建议次月3日23:59，不能晚于学期审核截止   | 校方          |
| D05  | 扫码驳回的卡是否作废           | 默认直接VOID，补发新卡                   | 校方          |
| D06  | 教师是否只能审自己名下卡       | 默认是，同时检查学生在任教范围           | 校方          |
| D07  | 六育故事是否允许发卡+1         | 系统允许配置G类目，正式类目待学校审批    | 校方          |
| D08  | 故事月份完成规则和量规         | 教师确认分；缺月不自动0分                | 教研组        |
| D09  | 故事外部成绩如何与月度故事合成 | 默认不自动合成，批准后才设权重           | 教研组        |
| D10  | 荣誉9档内部积分及同项去重      | 建议省9/8/7、市6/5/4、区3/2/1            | 校方          |
| D11  | 综合分80/15/5、20分和12分封顶  | 试行值，需公平性评审；无奖状最高95       | 校方          |
| D12  | 家长寄语通过什么渠道           | 三角色先学生代录标注来源；非必填         | 校方          |
| D13  | 钉钉五育和外部故事接口         | 先模板导入，API能力需测试授权            | 接入方        |
| D14  | 报告由谁最终发布、异议持续多久 | 管理员控制发布，截止按学期配置           | 校方          |
| D15  | 未成年人数据保留与日志权限     | 单独制度批准，按最小必要处理             | 校方/技术     |
