# 小学生 BMI 标准计算与体型评价技术设计

状态：已通过工程审查，待用户最终确认。
背景：系统需支持依据国家标准对小学生身高体重自动计算 BMI 并评定体型分类，可通过后端 `.env` 配置选用不同的国家/行业算法标准，并在报告单与评价表格中采用双行纯文本（方案 A）清晰呈现。

## 一、 目标与边界

### 1. 核心目标
1. **多标准算法支持**：在后端实现两套国家评定标准：
   - **卫健委标准（WS/T 586-2018 + WS/T 456-2014）**：按学生性别与半岁周岁年龄档（6.0～12.0 岁），评定 5 类体型（中重度消瘦、轻度消瘦、正常、超重、肥胖）。
   - **教育部体测标准（2014 年修订）**：按学生性别与年级（一至六年级），评定 4 类等级（低体重、正常、超重、肥胖）及体测得分。
2. **环境配置动态切换**：在后端 `.env` 中通过 `BMI_EVALUATION_STANDARD`（可选值：`WS_T_2018`、`MOE_2014`，默认为 `WS_T_2018`）进行全局配置，无需改动业务代码即可无缝切换。
3. **数据输入链条**：在 Excel 导入（体测/成绩信息）中增加对“性别”（男/女）与“出生日期”（YYYY-MM-DD）的解析与存储支持。
4. **视觉呈现（方案 A）**：在学生评价明细表与报告单的“健美少年”栏目中，BMI 所在表格单元格采用雅致双行纯文本排版（上方为数值如 `11.52`，下方为体型结论如 `中重度消瘦`）。

### 2. 非目标（Non-Goals）
- 不在前端增加供教师/学生动态切换标准的下拉框（算法标准为全校/全系统统一的配置项）。
- 不在一张报告单上同时混合输出两套不同标准的评定结论。
- BMI 体测分值不直接联动改写教师评定的 `fitness_level_star`（体测等级星级），保持现有评价流数据隔离。

### 3. 防退化目标（Anti-Goals）
- 不破坏现有六育 V2 报告单的打印布局与页面分页。
- 不影响现存历史评价数据及其他学科字段的数据完整性。
- 不修改底层数据库核心表的实体字段（不引入高风险 DDL），充分复用既有 JSON 扩展字段。

## 二、 算法规则与计算口径

### 1. BMI 基础计算
$$\text{BMI} = \frac{\text{体重}(\text{kg})}{[\text{身高}(\text{m})]^2}$$
计算结果统一保留两位小数（四舍五入）。若身高 $\le 0$、体重 $\le 0$ 或任意一项缺失，则返回 `null`。

### 2. 算法分档边界处理（连续区间对齐）
国标表中虽然采用 $13.1 \sim 13.4$ 这类 1 位小数的表述，但实际判定时采用严格的连续左闭右开/半开区间，彻底消除 2 位小数计算结果（如 $13.04$、$13.45$）可能落入的数值空隙：
- 中重度消瘦：$\text{BMI} \le \text{轻度下限} - 0.05$（即 $< 13.05$ 对齐 $13.0$）；
- 轻度消瘦：$[\text{轻度下限} - 0.05, \text{正常下限} - 0.05)$；
- 正常范围：$[\text{正常下限} - 0.05, \text{超重下限} - 0.05)$；
- 超重范围：$[\text{超重下限} - 0.05, \text{肥胖下限} - 0.05)$；
- 肥胖范围：$\ge \text{肥胖下限} - 0.05$。
*（亦等价于将 2 位小数 BMI 四舍五入保留 1 位小数后再对齐国标表格，确保判定严密可复现）*。

### 3. 算法 1：国家卫健委标准（WS/T 586-2018 / WS/T 456-2014）
- **适用配置**：`BMI_EVALUATION_STANDARD=WS_T_2018`
- **输入维度**：性别（男/女）、周岁年龄（精准到半岁档）。
- **年龄获取与推断规则**：
  - **首选精确计算**：若导入数据中包含出生日期（`birthDate`）和测量日期（`measurementDate`），通过实际日期间隔折算精确年龄：
    $$\text{Age} = \frac{\text{measurementDate} - \text{birthDate}}{365.2425 \times 24 \times 3600 \times 1000}$$
    并就近归整到最近的 0.5 岁档（如 $[6.25, 6.75) \implies 6.5$ 岁）。
  - **缺省自动推断（按中国标准入学年龄）**：若数据中未提供出生日期或具体年龄，系统自动依据我国《义务教育法》儿童年满 6 周岁入学的法定标准结合就读年级进行推断：
    - 一年级 $\implies 6.5$ 岁档（上学期 6.0~6.5 / 下学期 6.5~7.0 岁中间基准）；
    - 二年级 $\implies 7.5$ 岁档；
    - 三年级 $\implies 8.5$ 岁档；
    - 四年级 $\implies 9.5$ 岁档；
    - 五年级 $\implies 10.5$ 岁档；
    - 六年级 $\implies 11.5$ 岁档。
  - **边界兜底**：计算出的年龄低于 6.0 岁按 6.0 岁边界档处理，高于 12.0 岁按 12.0 岁边界档处理。若缺失性别，则保留 BMI 数值，体型结论显示为“—”。
- **评定标准对照表**：

### 4. 算法 2：教育部体测标准（2014 年修订）
- **适用配置**：`BMI_EVALUATION_STANDARD=MOE_2014`
- **输入维度**：性别（男/女）、就读年级（1～6 年级）。
- **评定标准对照表**：
  - **男生**：
    - 一年级：低体重 $\le 13.4$ ｜ 正常 $13.5 \sim 18.1$ ｜ 超重 $18.2 \sim 20.3$ ｜ 肥胖 $\ge 20.4$
    - 二年级：低体重 $\le 13.6$ ｜ 正常 $13.7 \sim 18.4$ ｜ 超重 $18.5 \sim 20.4$ ｜ 肥胖 $\ge 20.5$
    - 三年级：低体重 $\le 13.8$ ｜ 正常 $13.9 \sim 19.4$ ｜ 超重 $19.5 \sim 22.1$ ｜ 肥胖 $\ge 22.2$
    - 四年级：低体重 $\le 14.1$ ｜ 正常 $14.2 \sim 20.1$ ｜ 超重 $20.2 \sim 22.6$ ｜ 肥胖 $\ge 22.7$
    - 五年级：低体重 $\le 14.3$ ｜ 正常 $14.4 \sim 21.4$ ｜ 超重 $21.5 \sim 24.1$ ｜ 肥胖 $\ge 24.2$
    - 六年级：低体重 $\le 14.6$ ｜ 正常 $14.7 \sim 21.8$ ｜ 超重 $21.9 \sim 24.5$ ｜ 肥胖 $\ge 24.6$
  - **女生**：
    - 一年级：低体重 $\le 13.2$ ｜ 正常 $13.3 \sim 17.3$ ｜ 超重 $17.4 \sim 19.2$ ｜ 肥胖 $\ge 19.3$
    - 二年级：低体重 $\le 13.4$ ｜ 正常 $13.5 \sim 17.8$ ｜ 超重 $17.9 \sim 20.2$ ｜ 肥胖 $\ge 20.3$
    - 三年级：低体重 $\le 13.5$ ｜ 正常 $13.6 \sim 18.6$ ｜ 超重 $18.7 \sim 21.1$ ｜ 肥胖 $\ge 21.2$
    - 四年级：低体重 $\le 13.6$ ｜ 正常 $13.7 \sim 19.4$ ｜ 超重 $19.5 \sim 22.0$ ｜ 肥胖 $\ge 22.1$
    - 五年级：低体重 $\le 13.7$ ｜ 正常 $13.8 \sim 20.5$ ｜ 超重 $20.6 \sim 22.9$ ｜ 肥胖 $\ge 23.0$
    - 六年级：低体重 $\le 14.1$ ｜ 正常 $14.2 \sim 20.8$ ｜ 超重 $20.9 \sim 23.6$ ｜ 肥胖 $\ge 23.7$
  - 体测分值映射：正常得 100 分，低体重/超重得 80 分，肥胖得 60 分。

## 三、 数据导入、数据模型与存储设计

### 1. 存储设计（无 DDL 侵入）
- **无须修改数据库物理表结构**：
  - 学生的 `gender` 与 `birthDate` 作为体测健康测量元数据，统一写入已有的 `evaluation_source_record.payload_json` 以及 `student_term_evaluation.section_meta` 的扩展属性中；
  - 既有学生如果已录入过学籍基础数据，则优先继承已有信息。

### 2. 导入解析与兼容处理（`reportCoreV2Imports.js`）
- **列名别名扩充**：
  - `性别` $\to$ `gender`（值自动清洗规范化为 `'MALE'` / `'FEMALE'` 或统一汉字 `'男'` / `'女'`）；
  - `出生日期` / `生日` $\to$ `birthDate`（规范化为 `YYYY-MM-DD`）。
- **兼容性原则**：
  - “性别”与“出生日期”列为**兼容可选列**，老版本缺少这两列的 Excel 文件依然可正常导入，不报致命错误；
  - 缺失出生日期时，按前面定义的一至六年级标准入学年龄自动推断。

### 3. 数据契约（向后兼容扁平协议）
为彻底避免 React 渲染崩溃及历史测试断言破坏，系统保持 `values.bmi` 为纯数字型，同级增加分类结论字段：
```javascript
values = {
  ...otherFields,
  bmi: 11.52,                 // 纯数字或 null，100% 保持历史消费端完全兼容
  bmi_label: "中重度消瘦",     // 体型结论文本（如 "正常"、"中重度消瘦" 等）
  bmi_score: null,            // 教育部标准下的体测分值（如 100/80/60），卫健委标准下为 null
  bmi_standard: "WS_T_2018"   // 当前生效算法代码
}
```

## 四、 页面呈现与报告渲染（方案 A）

### 1. 后端报告渲染服务（`backend/services/reportRenderV2.js`）

  `身高 / cm | 体重 / kg | BMI | 视力左 | 视力右 | 跳绳 / 次`
- BMI 单元格采用双行纯文本（方案 A）：
  ```html
  <td class="bmi-cell">
  ```


  若存在 `bmi_label`，则以微排版方式在数值下方渲染结论文字；若无数据则保持 `—`。
