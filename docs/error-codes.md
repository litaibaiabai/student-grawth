# 错误码约定文档

前后端统一的业务错误码映射表。所有 API 响应遵循 `{ code, message, data }` 格式。

## 通用错误码

| Code | HTTP Status | 含义 | 说明 |
|------|-------------|------|------|
| 200 | 200 | 成功 | 请求处理成功 |
| 400 | 400 | 请求参数错误 | 请求参数缺失、格式不对或业务语义错误 |
| 401 | 401 | 未认证 | 未登录、token 无效或已过期 |
| 403 | 403 | 无权限 | 当前角色无权访问该资源 |
| 404 | 404 | 资源不存在 | 请求的资源或接口不存在 |
| 409 | 409 | 数据冲突 | 数据已存在（如用户名重复） |
| 422 | 422 | 参数校验失败 | 表单/参数校验不通过 |
| 429 | 429 | 请求频率限制 | 请求过于频繁，请稍后重试 |
| 500 | 500 | 服务器内部错误 | 服务端未预期的错误 |

## 业务错误码（预留范围 1000-9999）

| Code | 含义 | 说明 |
|------|------|------|
| 1001 | 登录信息错误 | 用户名或密码错误 |
| 1002 | 账号已禁用 | 账号被管理员禁用 |
| 1003 | 账号已锁定 | 多次登录失败后锁定 |
| 2001 | 创建失败 | 资源创建失败 |
| 2002 | 更新失败 | 资源更新失败 |
| 2003 | 删除失败 | 资源删除失败 |
| 3001 | 文件上传失败 | 文件大小、格式或上传过程出错 |
| 3002 | 文件不存在 | 请求的文件未找到 |

## 前端处理策略

| Code | 前端行为 |
|------|---------|
| 200 | 正常处理 data |
| 401 | 清除 token，跳转登录页 |
| 403 | 展示"无权限"提示 |
| 422 | 展示校验错误信息 |
| 429 | 展示"请求过于频繁"提示 |
| 500 | 展示"服务器繁忙"提示 |

## 扩展方式

如需新增错误码，请在此文档中添加，并同步更新：

1. `backend/constants/errorCodes.js` — 后端常量定义
2. `frontend/src/util/request.js` — 前端错误映射（如需特殊处理）
