# 管理员端闭环交付说明

已完成七模块实现、实际数据库迁移、隔离测试数据和三角色 MCP 闭环演示。验收结果见 [验证记录](verification.md)，30 步预期、实际与截图见 [演示脚本](demo-script.md)。

## 功能模块与三端关系

| 管理员模块 | 具体职责 | 与教师端、学生端的数据关系 |
| --- | --- | --- |
| 发布中心 | 查看有效名单、逐项完整性和班主任确认；准备全校快照，统一发布；登记更正阶段 | 教师核对并确认完整报告；管理员不代填评价。准备期间不提前向学生展示；统一发布后学生读取本人冻结版本，任课教师读取获授权的本班报告 |
| 学籍与账号 | Excel/CSV 导入教师、学生；差异预览、原子提交；筛选账号；启停与重置密码 | 学生账号关联已导入班级；教师账号供班主任和学科配置使用。停用或重置撤销旧登录令牌 |
| 班级管理 | 仅导入班级；紧凑卡片；学生名单、教师配置两个页签；每班一位负责教师和各科学科教师；调班预览 | 班主任拥有本班寄语与完整报告审核范围；真实任课关系决定直评和自动课程卡。调班保留事实，按最终班级重算，并使相关确认失效；不修改历史报告 |
| 月度卡额度 | 全局默认初始100张；维护学科覆盖数量；空白继承，0暂停 | 按班级×学科×月份自动为实际任课教师生成卡片。语文60、数学70、英语75；同师三个班语文共180。额度配置改变不重写既有批次。更换任课教师沿用该班科当月剩余额度，撤销旧未用凭证并转交剩余卡片，不重复增发 |
| 数据统计 | 沿用已重构的卡片、自评、荣誉、故事新统计口径、筛选和明细；完整性/缺项由发布中心展示 | 从有效学籍和同一来源事实汇总，真实0保留，不适用排除相应分母。管理员查看统计，不查看私有故事全文或代审批报告 |
| 学期配置 | 本学期基本信息、截止与报到安排；查看固定V2政策；新建并切换下一学期 | 新学期从空班级、空评价开始，重新导入；不复制历史评价。V2不开放旧版固定目标分规则编辑；发布准备期间阻止不一致变更 |
| 操作记录 | 按时间、类型筛选导入、配置、更正和发布记录，导出安全元数据 | 与原业务来源、操作者和版本关联。密码及其哈希、登录令牌、卡片凭证、私有正文和文件路径不得进入审计列表/导出；非秘密发布批次标识用于追溯 |

管理员端不提供体测原始值录入；体测仍由教师通过现有综合成绩 Excel 上传。班级不提供手动新建、状态或进度页签。

## 数据库迁移

现有七表V2新增 `school_class`，形成八表增强模式；负责人来自该表，任课仍来自 `teacher_teaching_assignment`。`evaluation_source_record` 继续保存导入预览、有效事实和审计，`student_term_evaluation` 保存当前投影，`term_report` 保存冻结报告。

```sh
REPORT_DB_NAME=student_growth node backend/scripts/migrateAdminClasses.js
# 检查无冲突并完成可恢复备份后，显式追加迁移
REPORT_DB_NAME=student_growth node backend/scripts/migrateAdminClasses.js --apply
REPORT_DB_NAME=student_growth node backend/scripts/migrateAdminClasses.js
```

迁移默认只读，重复apply不重复建表/回填。检查脚本验证已知表、字段类型、自增与默认值、索引、CHECK和复合外键。存在未知结构或负责人冲突时拒绝apply。本机实际升级前已完整备份并恢复验证，原七表行数保持一致；证据见 verification.md。

## 独立测试数据

```sh
node backend/scripts/seedAdminClosureDemo.js
```

脚本每次创建全新的 `liuyu_report_test_admin_demo_*`；拒绝覆盖已有库。可用 `ADMIN_DEMO_DB` 明确指定符合此命名规则的新库。输出仅写本机忽略目录，账号文件权限为600。初始仅管理员与完整V2学期；2名教师、3个班级、1名学生、60项教师成绩/体测的导入文件和明确标注虚构的奖状作为输入，业务结果均需通过实际操作产生。

测试数据库与本机 `student_growth` 分离；不向业务库混入演示师生，不调用付费模型。完整HTTP自动化和MCP界面演示分别记录，不相互冒充。

## 启动独立演示

```sh
node backend/scripts/runAdminClosureDemo.js
```

默认创建新的演示起点，API绑定127.0.0.1:19980，网页为http://localhost:19981。端口占用会报错，不结束其他服务。用ADMIN_DEMO_MANIFEST可恢复指定演示库；不会自动清空已有状态。Ctrl+C只关闭本脚本启动的服务，保留演示库与证据。

演示寄语使用明确标注“演示固定文案，未经AI生成”的固定响应，教师需改写后审核；奖状由教师人工核对。它不代表生产ASR/OCR/LLM服务已经接通。讲故事录音数量与正式评分分开，未评分不伪造报告分数。

## 本次验收结果

### 恢复持久演示环境

原临时演示库被移除后，已从完整闭环回归夹具恢复独立的 `liuyu_report_pilot_admin_demo_v3`。它与业务库分离，包含虚构师生、班级和已发布报告，四个账号统一使用演示密码。恢复已存在的环境请显式指定清单：

```sh
ADMIN_DEMO_MANIFEST=output/report-core/admin-closure/liuyu_report_pilot_admin_demo_v3/manifest.json node backend/scripts/runAdminClosureDemo.js
```

不带清单启动仍会创建只有管理员的新库，教师和学生需要实际导入。启动器只额外允许上述专用持久库名，不允许指向业务库。清单和数据库是本机运行数据，不随Git提交。
