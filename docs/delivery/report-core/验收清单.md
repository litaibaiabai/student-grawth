## 自动评分的真实限制

用户指定的Dashscope兼容接口与qwen3.6-plus已接入。真实虚构故事调用返回HTTP400 / Arrearage（供应方账号状态异常）。没有伪造模型成功；浏览器闭环通过教师异常复核完成三类故事，记录TEACHER_REVIEW。恢复账号后可在教师材料入口重试自动任务。奖状图片识别还受模型视觉能力约束，无法识别时由教师查看原图确认。

## 重跑

使用Node >=22.12且本机可访问MySQL，backend/.env配置仅用于连接；测试自动创建/清理liuyu_report_test_*库，不读写原业务数据。

```bash
npm test --prefix backend
npm test --prefix frontend
npm run build --prefix frontend
node frontend/tests/report-core-flow.cjs
node frontend/tests/report-core-preview.cjs
REPORT_PERF=1 NODE_ENV=test node --test backend/__tests__/report_core_performance.test.js
```

Playwright默认使用当前环境的bundled安装；其他机器设置PLAYWRIGHT_MODULE为本机安装的playwright绝对路径，Chrome必须可用。打印验证需要pdfinfo（Poppler）。证据为被git忽略的output/report-core/，不提交私人材料或凭证。
