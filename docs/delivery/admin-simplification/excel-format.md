# 一份 Excel 完成学期初始化

只接受 `.xlsx`、不超过10MiB、五表合计不超过10000条数据。工作表名与第一行表头必须精确匹配；请直接下载当前管理员页面模板。

| 工作表 | 必填表头 | 可选表头 |
|---|---|---|
| 学期 | 学年、学期序号、学期名称、开始日期、结束日期 | 采集截止日期、下学期报到日期、设为当前学期 |
| 教师 | 教师账号、姓名、初始密码 | 无 |
| 班级 | 年级、班级、班主任账号 | 班级名称 |
| 学生 | 学号/账号、姓名、年级、班级、初始密码 | 无 |
| 任教关系 | 年级、班级、学科、教师账号 | 无 |

“初始密码”表头必须有；新增账号须填写至少10字符且不超过72字节的密码，既有账号留空，重导入不重置密码。账号及密码单元格必须为文本，`00123` 保留前导零。账号/姓名不超过64字符，学期名称不超过80字符；禁止公式、重复表头、重复学生、同班同学科多个教师以及跨表找不到的账号/班级。数据库大小写/重音等价的账号冲突会明确报错。

学期表恰好一行。学年例如 `2026-2027`（连续两年），学期序号1或2。日期使用真实 Excel 日期或 `YYYY-MM-DD`；开始早于结束，采集截止在区间内，留空默认结束日期。“设为当前学期”填“是”或“否”，空白默认“是”。年级/班级填正整数；班主任账号和任课账号须能在教师表或现有本校账号中解析。

学科支持：道德与法治、语文、数学、科学、英语、体育与健康、音乐、美术、信息科技、劳动、综合实践活动、地方课程。每行任教关系指定一个班、一个学科及一个教师；同一教师可有多个班/学科。管理员导入后只能查看这些关系。

预览显示教师、班级、学生、任教关系的新增/更新/不变数量及脱敏差异，确认前不写入。错误示例：“教师 / 第1行 / 工作表 / 缺少工作表”；任何错误均拒绝整单。预览绑定管理员身份、学校和账号版本，30分钟过期；预览后名单发生变化须重新预览。同一文件重复确认返回原结果；遗漏记录保留，不能靠省略行删除已有学籍。

初始化卡片后不能借重新导入修改课程、班级映射或学期日期；需新学期使用新工作簿。体测原始值由对应教师在“综合成绩”上传独立成绩工作簿，本管理员工作簿不包含成绩/体测数据。
