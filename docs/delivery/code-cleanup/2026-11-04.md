# 2026-11-04 前后端废弃代码清理

## 审计方法与边界

从 `frontend/src/main.jsx` 和 `backend/app.js` 出发，解析静态 import、re-export、require 和动态 import 的字面量路径；将后端全部维护脚本另列为有效入口，并核对全仓库调用、测试与历史资料。npm 包路径和运行器的可配置 Playwright 路径不视作废弃文件。

只移除已确认没有业务调用方的实现。V1 学期、旧卡凭据、历史冻结报告仍有实际分支，因此保留相关实现、字段契约和迁移工具。未修改正式数据库、私有文件、上传材料及历史报告，验证使用临时测试数据库。

## 清除函数、接口和样式

- `backend/db.js`：删除隐式全局连接池、旧 `pool` getter、`execute` / `query` 快捷接口；保留所有当前调用使用的 `createDbPool` 和 `dbConfig`。
- `cardCredentials.js`：删除旧 allocation/serial 字段拼接函数 `credentialContext`；`printKey` 保持内部使用，现有加密、解密、哈希行为不变。
- `reportCoreV2Imports.js`：删除无调用的 `buildV2Workbook`，保留当前教师模板 `buildScoreTemplate`；ZIP 校验函数仍内部使用。
- `termDates.js`：删除无调用的 `monthsOf`，保留实际使用的 `day`。
- 前端删除无调用的 `StatusBadge`、`EmptyState`、`ErrorFallback`，保留实际使用的错误边界、星级选择器与确认对话框。
- 前端删除仅被互相转导出的 `StudentModule` / `TeacherModule` / `ManagerModule` 注册表和未使用的组件聚合导出；实际角色路由继续直接调用三个 View。
- 将仅在模块内部使用的 `selfTexts`、`cardSubject` 设为内部实现。
- 清除 8 处未使用的后端导入绑定，以及获奖评审、班主任寄语中已移除标题和提示对应的废弃样式。

## 保留内容

- `LegacyAwardUpload`、V1 自评和故事表单、教师 V1 评审与特长维护：当前 schemaVersion 条件分支仍会加载。
- 历史学期、旧卡批次、UTC 时间切换、V2 来源审计、冻结报告渲染与读模型兼容逻辑：当前业务、迁移或维护脚本仍使用。
- `backend/scripts`、`docs/database`、`sql`、现有备份和恢复流程：仍属于运维与历史追溯入口。
- 历史文档中的旧路径作为当时证据保留；当前代码结构与本记录为准。
