# 2026-11-04 backend/services 分类

49 个服务文件按业务职责迁入 11 个目录：auth、core、cards、evaluation、reports、imports、materials、stories、registry、statistics、infrastructure。文件名、导出名称、HTTP 路由和业务计算规则保持不变；没有添加旧路径转发层。

目录职责及完整文件索引见 [services/README.md](../../../backend/services/README.md)。

## 同步更新范围

- 服务内部的相对 require，以及配置、middleware、db 和迁移脚本的相对引用。
- 后端路由、启动器、脚本、测试和测试 helper 的服务引用。
- 前端模型测试和浏览器联调脚本的后端服务引用。
- 字体、内置故事音频、来源私有文件目录和人脸 worker 的 __dirname 资源路径。
- README 与文档索引；历史资料中的路径不批量改写，按服务文件名查新目录即可。
