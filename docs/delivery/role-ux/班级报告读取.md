# 班级报告读取与版本边界

教师接口：

- `GET report-core/report-classes?termId=...`：当前有效任教的全部班级，去重职责，含班主任标志、学生人数及全量完成/确认/发布计数。
- `GET report-core/report-students?termId=...&grade=...&classNo=...`：学生摘要，支持keyword、status=all/missing/confirmed/published/ready/draft与25/50/100行分页。摘要只有六板块进度、等级/星级计数及权限，无自述/体测原始值/故事正文。
- `GET report-core/report-detail/:studentId?termId=...&version=current|published&scope=detail|full`：任课教师可detail，班主任可full。学生自己的已发布报告仍沿原current报告接口读取。

详情固定返回model、html、viewVersion、scope、revision、fingerprint、templateVersion、ruleVersion、configVersion、releaseVersion、publishedVersion、missingItems、permissions。不适用版本为null。published只读，不能用冻结修订确认或改写当前草稿。

DETAIL_ONLY在服务端不生成正面，也不返回narratives、私有来源摘要或完整HTML副本。任教撤销后，已发布报告同样拒绝查看；跨学校、无关班级、管理员和学生不能使用教师浏览器接口。新读取接口明确private/no-store。

新发布在既有snapshot_json冻结renderedDetailHtml及哈希，发布快照先JSON归一化再计算总哈希，包含真实日期字符串。读取已发布明细校验总快照及明细哈希，模板文件升级不重渲染旧报告。历史CORE缺安全冻结明细、LEGACY无法安全裁剪时，普通教师得到明确不支持；班主任可沿完整版历史读取。

已发布与当前缺项是两个维度：一个学生可同时计入两者，不能把各状态人数简单求和当作总人数。全校发布名单、工作台与摘要继续以该学期学籍为准，账号启停不删除历史名单。
