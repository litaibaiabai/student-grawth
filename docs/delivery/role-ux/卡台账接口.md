# 卡台账真实读取接口

Task2实现于隔离分支codex/role-ux，不是静态原型。

入口均为`/api/v1/report-core/card-ledger/`：summary、cards、cards/:id、usage、audits。教师只读本人；管理员必须指定本校teacherId；学生403。校验学期及月份范围，ID用字符串，limit=25/50/100，游标绑定角色/过滤/排序。

三个统计对象必须分别标注：

- `summary`：所选教师与月份范围的完整额度、计划、纸卡状态及净积分，不能按学生过滤重新解释Q/G/剩余额度。
- `filteredSummary`：当前班级/学生/方向/状态/日期过滤的来源统计；不把它当新配给学生的额度。
- `eventSummary`：usage视图按筛选事件计算positive/reversals/net；跨月冲正归原评价月，事件日期仍是实际冲正时刻。事件日期筛选时标签为“筛选事件变动合计”。

查询一个事务读取元数据与来源流，采用数据库流分批读取，内存保留当前页及小型班级/指标/学生汇总，不把全校来源加载到前端。SQL不查询凭证列，输出DTO不含token/hash/ciphertext、健康数值、学生自述或故事原文。详情包含原卡元数据、作废/冲正原因及生成/领取/作废/冲正/原码打印请求轨迹；不声称已实际出纸。

默认截至当前服务器时间；显式asOf使用记录/审计回放，未来领取不暴露给历史时点的收卡学生。历史额度/计划/发行时刻缺证据时返回null、historyCompleteness、unknown计数，不用当前值伪造历史。generatedRecords是匹配的原记录数量；generated未知时不能将它冒充历史已发行量。

时钟边界来自显式SOURCE_CLOCK_BASELINE审计，新UTC边界后可判定来源时间；已核实旧偏移只在读取时换算，未知旧时间不硬归月份。未做真实业务库时钟切换。

验证包含80卡（52领取、2冲正、2作废→26待领、净分50）、121卡跨旧100条边界分页、HTTP角色/详情/日志、跨月冲正、历史asOf、未知时钟与历史额度。测试只使用liuyu_report_test_*。

初版采集121卡典型EXPLAIN，学生快照关联使用uk_eval_student_term；发现原始冲正连接未用生成唯一键，已改为reversal_of与原ID关联，以复用uk_source_reversal_once。不新增DDL或统计表。该样本不是200万来源性能验收，Task16仍需实际规模验证，必要时再针对actor过滤补最少索引。

## 导出与打印

- `GET card-ledger/export?view=events|cards|students|indicators|monthly`：复用列表筛选、权限；UTF-8 BOM CSV，不受屏幕分页限制。50000行上限，超限422，请缩小范围。文本公式防护、编号文本化；真实数值仍为数值。响应断开回滚读取事务并释放连接。
- `GET card-ledger/print`：相同视图和筛选，最多1000行，返回转义HTML、行数及截至时间，重复表头、A4横向浏览器打印。
- `POST card-quotas/:id/print-requests`：含requestKey，可选grade/classNo或cardIds；记录PRINT_REQUEST及原卡范围。默认只选当前可领取原卡，不增加卡量/积分。
- `GET card-print-requests/:id/file`：只读下载。单班PDF，全部班级ZIP内每班一个中文PDF。下载时再次检查全部选中卡，若已领/失效/作废则409要求刷新；同一卡号和原二维码凭证重复使用。打印请求不代表物理打印成功。
- 旧token和ZIP地址同样检查当前可领取状态，不能绕过。

## 统一工作台读取

`GET report-core/workspace?termId=...&grade=...&classNo=...&subjectCode=...`：counts为完整授权范围统计，tasks按25/50/100分页，nextCursor绑定账号和筛选；classRows为授权班级去重人数。任务返回字段/来源定位与明确负责人，不返回报告文字、体测值或故事原文。管理员只读完成状态，学生仅本人，教师只负责班级。

`GET report-core/teachers?q=...`：管理员搜索本校启用教师，姓名与账号共同区分同名教师。

名单取当学期student_term_evaluation，账号停用不删除历史学籍；显式排除采用section_meta.roster.included=false。故事阻断仅包含requiredMonths内当前生效批次的待处理ITEM，未提交新草稿不替换已生效批次。
