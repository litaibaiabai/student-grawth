# 教师直评、学业录入与材料审核

直评在一个页面完成：多选学生 → 六育板块 → 一级分类 → 二级指标 → 可选说明 → 每人记1分。分类按所选学生的班级任教权限取交集，37个有效叶节点，不提供劳美/故事发卡。重复点同一父分类不丢失二级选择，真正改变学生/父分类会清空下级。成功后清空本次选择，失败保留；第二次有意相同直评使用新请求键。

学业录入是一行一学生的横向滚动表，可按班级/科目筛选，从单格开始粘贴多行多列，也可载入Excel。填写空白保持旧值，禁用格不可写；预览集中列出全部行/字段错误，存在错误不产生可提交批次。确认前可核对学生与每个修改项。

材料接口按当前职责与状态返回allowedTargets、canRecognize、canRetry、canReject、canRevoke、canResubmit。教师在同屏查看奖状原图或故事正文、评分项、认定依据；审核、重试、撤回均由服务端重新检查职责/当前状态。学生与教师特长评分仍按稳定项目ID分开保存。

CARD_CLOSED是一次采集核对，晚到有效积分会重算并失效旧确认。NO_AWARD不绕过待认定材料；奖状认定后撤回会失效旧无奖声明，需要重新核对。失效事实沿用现有FORM记录，不新增表。旧故事批次不提供重试/认定动作。

验证包含：两名学生空说明直评两次，各得到2条真实DIRECT来源；学业全部错误与空白保留；持有学生行锁时并发认定/重试；拒绝/撤回竞争；无关学科直接URL越权；零卡结算、晚到积分、无奖后新材料/撤回/再次核对；八名学生三角色六来源到全校发布、A4打印。
