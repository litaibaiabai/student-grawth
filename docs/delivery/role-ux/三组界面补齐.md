# 三组延期界面补齐（2026-10-30）

用户在核心改版交付后要求“继续”，本轮补齐此前公开的三组延期项。沿用同一设计、六张业务表和既有权限，不新增依赖、生产库操作或线上LLM调用。

## 月度额度

当前页模板使用教师账号而非数据库ID，保留前导零；兼容旧ID模板。同校账号解析后统一按内部ID加锁，账号/ID指向同一教师也检测重复。预览一次返回全部行的账号、启停、重复、数值和Q/P/G下限错误，任一错误整批不生成有效预览。目录展开任教班级、学科与班主任职责。文件模式可逐行修正；切换手动模式先保护未提交文件，取消则保留输入。迟到文件/预览不恢复过期内容。

## 班级报告

本地搜索全部负责班级，显示每班数据齐全、缺项、确认、发布计数；每页25/50/100人与URL绑定，切页大小清游标，后端游标也校验页大小。学生摘要六育按钮直达对应报告板块，返回保持原查询/页大小。定位仅修改屏幕DOM的滚动/焦点，不修改冻结HTML、快照哈希或打印测量；普通任课仍只能安全明细。

## 卡片管理

六育→一级→细分指标联动清理下级选项，劳美/故事明确不发卡。统计卡可进入对应纸卡明细或额度计划：总盘下钻明确清除学生/方向等筛选并沿用所选月份，其他月份计划不混入；未保存计划在查询/重置前有保护。班级分配可展开既有indicatorPlans，历史额度/计划/卡状态完整性与未知时间/状态/生成时点分别显示，不补造0或月份。
