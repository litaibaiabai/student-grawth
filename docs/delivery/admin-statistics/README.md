# 管理员 · 学生数据统计

入口：管理员侧边栏 **数据统计**，地址 `#/manager/statistics?termId=<学期ID>`。管理员当前仅保留学籍账号管理、卡额度管理、数据统计。

## 已实现

- **卡片与奖励**：成功领取二维码卡、有效无卡奖励、学生覆盖率；各学科对比及奖励方式占比；可展开学生的有效奖励记录，含学科、项目、教师、时间及记录分页。
- **自我评价**：完成人数、完成率、进行中/未开始/无适用项、已评价项目数量；年级/班级完成情况，一至三星占比和每个学生的进度。
- **荣誉上传**：上传学生、累计份数、已认定、待处理；认定级别及不予认定、已撤回、识别失败分布；各状态学生明细可对账。
- **故事参与**：讲/听/写分别统计参与人数和作品或有效完成次数，同时展示任一方向参与的去重人数与参与者人均数量。

学期、年级、班级控制统计范围；卡片学科筛选同时影响概览、图表和明细。姓名/学号、状态筛选只影响学生明细，不改变概览分母。支持 20/50 人分页、键盘标签切换、错误重试、取消过期请求和零数据空态。320px、390px、1440px 布局已检查，四标签在窄屏同时可见。

## 口径与边界

仅支持六育 V2 学期。只允许管理员查询本校数据，使用学期名单快照并排除已转出、不适用及未纳入统计的学生。学生没有记录仍保留在明细中。

奖励撤销按原记录排除，不把净分数当次数；优先采用来源学科，缺失时按评价目标映射，日常行为和未归属记录单列。自评只统计当前学生页面可填写的适用 SELF 星级项，不混入他评和旧版隐藏特长字段；占比按已评价项目数计算，无分母显示“—”。讲故事包含当前录音记录，历史根作品和写故事只统计当前有效提交版本一次，不以评分为参与前提。

管理员接口只返回统计及奖励元数据，不返回学生自述、故事正文、录音/证书文件路径或卡片凭证。响应设置 `Cache-Control: private, no-store`；同一次查询使用数据库一致快照。不新增表、不迁移数据库、不新增前端依赖。
