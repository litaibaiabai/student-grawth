• 独立家长账号、钉钉及外部小程序接口、外部故事加权合成、积分兑换、在线申诉、排名。
 
• 真实证书文件上传与对象存储、真实大模型调用、持久化任务队列、异步 PDF 文件生成和短期签名下载。
 
• 荣誉 REVOKED 撤销、报告发布后自动级联重算、归档后超管更正完整闭环、严格六项发布门禁。
 
• Redis / Spring Boot / MinIO / 独立 Worker 并非当前已集成技术；实施计划中的相关选型不作为本版现状。

5.2 登录、退出与范围判断
• 登录参数为 username/password，当前按 username 查第一条用户，没有 schoolId 登录选择；同名跨校账号的确定性需
 核对。
• 验证账户状态、BCrypt 密码后签发 JWT，携带 userId、schoolId、role、grade、class_no、classes；当前 classes 是签
 发时快照。
• requireAuth 校验签名与注销黑名单；黑名单查询异常时当前会降级放行，不能声称撤销会话在故障下仍严格生效。
 
• 退出将 Token 的 SHA-256 与过期时间写入 token_blacklist；前端清理本地登录态。
 
• 菜单按角色组织，前端路由仅要求登录；服务端 requireRole 与局部 assertStudentInScope 共同构成当前权限基础，尚未
 成为全入口统一范围守卫。

1. 管理员设置 quotaN 与 allocationJson，控制器校验各分配值合计等于总额并保存。

5.8 当前综合得分计算
 图 3 当前代码的数据汇集方式；最新故事覆盖 G、缺少确认态和版本筛选属于现行口径及风险，不代表最终校规
B = (D + Z + T + M + L + G) / 6
P = min(100, max(0, 净过程积分 / process_target × 100))
H = min(100, max(0, 已通过荣誉分 / honor_target × 100))
S = round(six_weight × B + process_weight × P + honor_weight × H, 2)
引擎读取 ACTIVE 规则；没有规则时当前回退80%/15%/5%、20次、12分。六维存在性检查通过才计算 S，否则返回
isComplete=false、缺失维度列表和 null 综合分。当前查询未严格限定 CONFIRMED 或明确最新版本，也会用最新已评
故事覆盖 G，故完整性含义仅是“当前 Map 中有六个值”。
示例仅说明现有公式：六维92、88、90、86、94、89，B≈89.8333；过程33次→P=100；荣誉8分→H≈66.6667；按回退
权重得到 S=90.20。实际评分政策是否采用该口径，需要单独确认。
边界需修正：均分0在现有返回表达式中可能被转为 null；无 ACTIVE 时自动回退规则，与 SPEC 不允许无生效规则发布的目标不同。当前
主要在查询/发布时计算，未发现完整的事件驱动重算任务链。
