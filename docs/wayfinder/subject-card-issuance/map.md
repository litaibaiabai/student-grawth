## Decisions so far

- [教师任教学科与每月领卡资格如何确定](issues/WF-CARDS-01.md) — 每位教师每月一份，按管理员指定的主教学科策略分配。
- [学科策略如何表达六育数量与比例](issues/WF-CARDS-02.md) — 配置月总张数与六育比例，各方向整数张数由系统推算。
- [月度自动生成何时生效以及如何避免重复配卡](issues/WF-CARDS-03.md) — 每月 1 日生成当月，首次启用及新教师补整份；已有卡时策略修改下月生效，待审期限不晚于次月 3 日及学期截止。
- [教师审核怎样选择子类并形成准确加分记录](issues/WF-CARDS-04.md) — 审核时确定两层子类，每张卡通过后固定加 1 分。
- [自动生成后的实体卡如何领取打印与重印](issues/WF-CARDS-05.md) — 管理员统一打印分发，领取按教师分组、含二维码的 PDF；重印使用同一批卡。
- [旧卡旧配额与已入账积分如何过渡](issues/WF-CARDS-06.md) — 现有卡片仅为测试；正式启用直接采用新规则，测试卡隔离且不占正式月度份额。
- [三个角色的最终操作与接口边界怎样收敛](issues/WF-CARDS-07.md) — 仅在有效学期覆盖月份发卡，角色、数据、接口与验收规格已完成交接审阅。
