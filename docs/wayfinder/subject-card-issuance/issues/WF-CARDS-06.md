# 旧卡旧配额与已入账积分如何过渡

## Question

从“逐教师月配额、卡片预绑定叶子指标”切换到新规则时，现有卡片、待审申领、旧配额和历史积分分别如何处理，才能避免重发、误加分或丢失历史依据？

需要明确：

- 切换从哪个月份开始；上线当月旧卡是否计入新的自动分配数量。
- 已印刷未申领卡是否继续有效；旧卡方向如何从原指标可靠回溯，原叶子分类是固定沿用还是审核时重新选择。
- 旧待审单采用哪套审核规则；已使用、已过期、已作废的卡是否只作为历史展示。
- 已入账流水与审计是否原样保留；如涉及更正，使用什么可追溯的更正流程，不能默默重写历史积分。
- 旧 `card_quota_rule` 是停止写入并归档，还是迁移为历史分配快照；如何与新学科策略区分。
- 旧制卡／配额写接口怎样退役，避免隐藏按钮后仍可通过旧接口继续按旧规则发卡。

依据：[现有表结构和卡片状态](../context.md)。此票只决定过渡规则，不执行任何数据库迁移或数据删除。

## Discussion comments

- 已询问：当前是否已有正式印刷、发放或供学生使用的实体卡，还是只有测试卡？
- 用户选择：“尚未正式发放，现有卡片仅用于测试”。

## Resolution comments

2026-10-26，参与者：用户与 Codex；由已领取本票的 Codex 记录结论。

用户确认的现状：旧版卡片尚未正式发放，现有卡片仅用于测试。因此不需要为已经正式流转的旧卡保留新旧两套审核和印刷链路；正式启用直接采用本地图确定的新规则。

Codex 据此收敛过渡方案，以下为实施默认，未声称用户逐条确认：

1. 旧测试卡及其关联申领保留为测试／归档数据，与正式卡片分配隔离；不占用新规则下教师的月度份额，也不能凭旧测试令牌领取正式积分。
2. 旧测试卡不自动转成新的方向卡，不根据其原叶子指标推导并授予一份正式配额，不尝试从旧哈希恢复可打印凭证。新规则启用时生成新的正式批次与二维码。
3. 正式列表、审核和打印流程只读取新的正式分配批次。现有旧待审测试单不自动审核或转成正式申请；已使用、已过期、已作废的测试卡保留原历史状态供核查。
4. 不改写旧积分与审计，也不擅自清空数据库。实施时保留迁移前备份，并用明确的测试／旧数据标记或归档方式隔离关联记录；隔离范围限定为旧测试卡及其关联申领、卡片积分，不能推定其他用户、学期、指标、导入成绩或非卡积分均是测试数据。
5. `card_quota_rule` 停止作为发卡依据，旧测试配置不转换为学科策略。管理员在新学科策略表中维护月总量与比例，并给教师指定主教学科。
6. 旧的逐教师配额写入与手动制卡接口退役，不能只隐藏按钮后继续允许调用。查询新月度分配结果采用只读接口；具体契约归入[三个角色的最终操作与接口边界怎样收敛](WF-CARDS-07.md)。
7. 新规则首次启用、自动补生成与生效月份继续遵守[月度自动生成何时生效以及如何避免重复配卡](WF-CARDS-03.md)，本次不指定实际部署日期、不执行迁移或数据删除。

现状事实和首版过渡边界已明确，本票关闭。无需实施的正式旧卡兼容分支不进入本次开发范围。
