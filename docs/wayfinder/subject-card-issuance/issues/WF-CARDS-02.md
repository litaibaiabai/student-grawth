# 学科策略如何表达六育数量与比例

## Question

每个学科的月度发卡策略如何表达总数量与六个方向的分布，才能既满足 70/20/10 的示例，又避免数量、比例和默认规则产生歧义？

需要明确：

- 配置以各方向整数张数为准，还是“月总数＋比例”为准；另一组值由系统推导还是也可编辑。
- 使用比例时如何取整并保证各方向张数之和等于月总量；比例或总量不合法时如何提示。
- 语文、数学、物理、美术以外的学科如何初始化；德育、劳育类学科的分布应逐学科配置，不能机械叠加“主方向70＋德育20＋劳育10”。
- 六个方向如何表达；故事方向卡片的审核计分边界交由[教师审核怎样选择子类并形成准确加分记录](WF-CARDS-04.md)明确，本票不改变故事评分算法。
- 零张、未配置方向的含义。停用策略、缺失策略及变更生效由[月度自动生成何时生效以及如何避免重复配卡](WF-CARDS-03.md)明确，管理员维护入口由[三个角色的最终操作与接口边界怎样收敛](WF-CARDS-07.md)明确。

依据：[用户已明确的示例与现有第六方向](../context.md)。示例不是对所有学科统一下发 100 张的授权。

## Discussion comments

2026-10-26，参与者：用户与 Codex。

- 已询问学科策略以“月总张数＋比例”还是“各方向张数”为配置依据。
- 用户选择：“填写每月总张数和六育比例，系统计算各方向张数（推荐）”。

## Resolution comments

2026-10-26，由 Codex 先领取后记录结论。

用户确认的业务规则：

1. 每个学科配置每月总张数和六育比例，二者是配置依据；各方向张数由系统计算，不另行独立编辑。
2. 每位教师按其主教学科获得一份分配结果；本票不将 100 张或 70/20/10 固定为所有学科的统一规则。

为让上述规则可以实施，以下作为 Codex 提出的技术默认，未声称用户逐条确认；后续可按用户说明调整：

- 月总张数为非负整数；六育比例均为非负有限数，合计应为 100%。无效输入应在保存前明确提示；后台同样校验。
- 六个方向沿用当前字典的 D/Z/T/M/L/G。界面完整显示六个比例，未分配的方向显式为 0，不隐含默认正比例；现有“故事”命名与计分边界仍以审核决策为准。
- 原始张数为“月总张数 × 方向比例”。先分别向下取整，再按小数余数从大到小补足剩余张数；余数相同时按固定方向顺序 D/Z/T/M/L/G 决定，保证可重复计算且六类之和准确等于总张数。0 比例方向不参与补足。
- 总张数为 0 时各方向均为 0，不生成卡；策略启停和生效月份仍由自动生成决策确定。
- 除用户给出的示例外，不擅自给其他学科设置正比例分配；实际比例由管理员维护。

示例：每月 100 张、智育 70%、德育 20%、劳育 10% → 智育 70、德育 20、劳育 10，其余 0。若改为 101 张，则为智育 71、德育 20、劳育 10。

配置的主要业务选择已经通过用户实际交流确认；本票关闭。启停、生效、界面和故事计分等剩余范围保留在前述开放票中。
